# B2B SaaS — 보안 점검 포트폴리오

## 고객
멀티테넌트 SaaS: 기업별 데이터 격리, 직원·관리자 역할, API 연동.

## 주요 위험 → 검증 사례

### 1. 다른 고객사 자료를 볼 수 있다면? (P02, 대표 사례)
- **위험**: 테넌트 신원이 클라이언트 헤더로만 결정되면 인증 자체 없이 모든 테넌트 열람.
- **SUNYEDO 검증**: Before 재현 (P02-RBAC-01) → After: 서버측 신원 + 테넌트 소속 검증, 정상 200 유지 (BA-01), 타 테넌트 403 (BA-03).
- **상태**: E4 완료 — 영업 우선순위 1순위 사례.

### 2. API 인증과 소유권 (P02+P04 통합)
- API 토큰 + 객체 소유권 검사 패턴. P04 무인증 조회 재현·보완 (BA-05).

### 3. AI·코딩 에이전트의 배포 권한 (Coding AgentRisk, 보조)
- 100과제·800회 실행 기반 권한·통제별 피해 시뮬레이션 (stored-result E3). `LAB_USD` 합성.
- **활용**: "AI가 작성한 잘못된 코드를 그대로 배포하면?" 카드 — 권한·승인 정책의 효과 정량 자료.

## 제공 서비스
테넌트 격리·역할 매트릭스 감사 → API 소유권 검증 PoC → 에이전트 실행권한 리뷰 → 재검증.
